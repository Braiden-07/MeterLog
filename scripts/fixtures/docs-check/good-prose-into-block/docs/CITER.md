# The case the proximity window EXISTS for — it must not be broken

A prose citation legitimately points a line or two INTO a block rather than at
its first line. The anchor here is inside the test body; the `it(...)` name it
quotes is one line above. This is not drift, and tightening the window globally
would have made it a failure.

See [`a revoked person can be re-invited to the same tenant`](../src/spec.ts#L5).
